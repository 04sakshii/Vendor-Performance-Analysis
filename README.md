\# Vendor Performance Analysis



\## Project Overview



This project analyzes vendor performance using sales, purchasing, and inventory-related data. It uses Python for data processing and exploratory analysis, SQL and database scripts for data ingestion, and Power BI for interactive visualization.



\## Tools and Technologies



\* Python

\* Pandas

\* SQL and SQLite

\* Jupyter Notebook

\* Power BI



\## Project Files



\* `Vendor Performance Analysis.ipynb` — Main vendor performance analysis notebook.

\* `Exploratory Data Analysis.ipynb` — Exploratory data analysis.

\* `ingestion\_db.py` — Database ingestion script.

\* `get\_vendor\_summary.py` — Vendor summary generation script.

\* `vendor performance analysis.pbix` — Power BI dashboard.



\## Analysis Goals



\* Examine vendor sales and purchasing performance.

\* Explore vendor contribution and sales patterns.

\* Identify vendors with low turnover.

\* Present insights through data analysis and visualization.



\## How to Explore



1\. Clone or download this repository.

2\. Install the required Python libraries.

3\. Open the notebooks in Jupyter Notebook.

4\. Review the Python scripts to understand the data ingestion and vendor summary process.

5\. Open the Power BI file in Power BI Desktop to explore the dashboard.



\*\*Note:\*\* Source datasets and database files are excluded from this repository because of their size. The notebooks and scripts may require the original data files and database to run. Update the file paths and database configuration as needed.
